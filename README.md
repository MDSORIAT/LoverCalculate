# ❤️ Love Calculator

A fun, beginner-friendly web application built with HTML, CSS, and JavaScript that calculates a random love compatibility score between two names.

---

## 🚀 Features

* **Interactive Form:** Takes two names (Your Name and Crush's Name) as input.
* **Random Compatibility Score:** Generates a random compatibility percentage between 1% and 100% using JavaScript (`Math.random()`).
* **Modern UI Design:** Styled with a romantic glassmorphism card layout, custom Google Fonts (Poppins), and soft pink gradient backgrounds.
* **Prevent Page Reload:** Uses JavaScript event handling (`event.preventDefault()`) to display results smoothly without refreshing the page.

---

## 🛠️ Technologies Used

* **HTML5** - Structure of the web application.
* **CSS3** - Styling, Flexbox layout, and visual design.
* **JavaScript (ES6)** - Core logic, input validation, and random score generation.
